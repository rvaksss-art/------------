Проанализируй текущую папку проекта тестового задания бизнес-аналитика.

Основные файлы проекта:

* `1. requirements.md` — согласованные требования;
* `2. prompt-OpenDesign.md` — исходный промпт для OpenDesign;
* `2.1 prompt iteration 1 - OpenDesign.md`;
* `2.2 prompt iteration 2 - OpenDesign.md`;
* `2.3 prompt iteration 3 - OpenDesign.md`;
* `2.4 prompt iteration 4 - OpenDesign.md`;
* `test1.html`–`test4.html` — предыдущие версии прототипа;
* `test5 - FINAL.html` — последняя и актуальная версия прототипа;
* `0.5 project plan.md` — план работы;
* файл Word с исходным тестовым заданием.

На этом этапе ничего не изменяй, не переименовывай и не удаляй.

Выполни анализ:

1. Прочитай требования и все промпты OpenDesign.
2. Изучи файл `test5 - FINAL.html`.
3. Проверь соответствие последней версии требованиям задания.
4. Проверь наличие следующих элементов:

   * выбор валютной пары;
   * отображение балансов;
   * ввод суммы;
   * автоматический расчёт;
   * текущий курс;
   * комиссия;
   * кнопка подтверждения;
   * состояние недостатка средств;
   * состояние изменения курса;
   * состояние истёкшего курса;
   * экран успешного обмена;
   * возврат в кошелёк;
   * отсутствие вертикальной прокрутки.
5. Проверь корректность расчётов и согласованность данных между состояниями.
6. Определи, какие элементы уже интерактивны, а какие пока только визуальные.
7. Проверь структуру HTML, CSS и JavaScript.
8. Составь список найденных несоответствий.
9. Предложи план дальнейшей реализации.

Отдельно предложи структуру следующих артефактов:

* `SDD.md`;
* `scenarios.feature`;
* `openapi.yaml`;
* `README.md`.

Не создавай и не изменяй файлы на этом этапе. Сначала покажи результаты анализа и план дальнейших действий.
